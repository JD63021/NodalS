WHAT FAILED
- Raw conservative form, implicit `u div(u)` correction: nonlinear SIMPLE divergence.
- Raw conservative form, explicit-lagged correction: also nonlinear SIMPLE divergence.
- Therefore do not reintroduce plain conservative correction into weakly divergence-free P1+BF3/P0.

EMAC FINDINGS
- EMAC nonlinear term: N(u)=2D(u)u + (div u)u.
- Diagnostic evaluation on the converged advective 20D solution passed:
  * tensor/quadrature EMAC identity: max relative error ~8e-15;
  * linear-momentum identity: ~1e-14 to 5e-14;
  * kinetic-energy identity: ~2e-14.
- Thus EMAC is algebraically appropriate for this weakly divergence-free mixed FEM setting.

SEGREGATED PICARD FORM
- Define B(v,a)=2D(v)a + (div v)a, so B(u,u)=N(u).
- Use a frozen advector a and solve each new component v_d with implicit scalar self part:
    a.grad(v_d) + 2 a_d d_d(v_d)
  while the remaining cross-component terms are deferred.
- Gate 3A: B(u,u)=EMAC to ~6e-16.
- Gate 3B: full B(v,u) = scalar-self + deferred-cross decomposition to ~4.4e-16
  for a deterministic v != u.
- A live 10D ~460k-tet segregated EMAC-Picard run showed residuals falling rather than the runaway
  behavior of the raw conservative attempts. This establishes viability, not production performance.

WHY THE FIRST LIVE EMAC CODE WAS SLOW
- It was correctness-first and intentionally unoptimized.
- It retained the old advective assembly for pressure rAU and then rebuilt diffusion/RANS/wall work
  separately for Ux, Uy, Uz (~4 common physical assemblies per SIMPLE iteration).
- Deferred EMAC cross terms were evaluated by brute-force nested cell tensor contractions.
- Do NOT use that implementation for performance conclusions.
